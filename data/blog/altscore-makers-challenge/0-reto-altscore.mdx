Welcome to the AltScore Makers Challenge collection! Here you'll find solutions and explanations for each programming challenge from Season 1.

> **A note on AI assistance:** I used AI tools (like GitHub Copilot and Claude) to help me implement some of the scripts faster.
> However, **the problem-solving approach and solution strategies were entirely mine**.
> AI helped me translate my ideas into code more efficiently, but I fully understand every line of code in these solutions.
> I believe in using tools that make me faster while staying sharp about the process. Modern developers should embrace AI as a productivity multiplier, not a replacement for understanding.

## Challenges

1. [La Sonda Silenciosa](/blog/altscore-makers-challenge/1-la-sonda-silenciosa) (100 points)  
   Calculate orbital velocity using distance and time measurements from an intermittent API.

2. [El Enigma Cósmico de Kepler-452b](/blog/altscore-makers-challenge/2-el-enigma-cosmico) (100 points)  
   Calculate the average resonance of stars in a nebula using a paginated API.

3. [La Búsqueda del Templo Sith Perdido](/blog/altscore-makers-challenge/3-templo-sith) (100 points)  
   Find the lost Sith Temple by analyzing Star Wars characters, calculating Force balance indices, and using the SWAPI to identify the planet with perfect Force equilibrium.

4. [La Búsqueda de la Forja Élfica Olvidada](/blog/altscore-makers-challenge/4-forja-elfica) (100 points)  
   Find hidden credentials by analyzing the Elven poem.

5. [La Última Defensa de la "Valiant"](/blog/altscore-makers-challenge/5-ultima-defensa) (300 points)  
   Shoot the enemy ship by predicting its movement using the radar data.

6. [La Infiltración en Ciudad Prisma](/blog/altscore-makers-challenge/6-ciudad-prisma) (100 points)  
   Calculate average Pokemon heights by type using the PokeAPI.

7. [Nave a la deriva](/blog/altscore-makers-challenge/7-nave-deriva) (150 points)  
   Create API endpoints for a damaged spaceship repair system.

8. [El Hechizo de La puerta mágica](/blog/altscore-makers-challenge/8-puerta-magica) (150 points)  
   Navigate through Altwarts magical door by collecting cookies and creating a teapot endpoint.

9. [Nave a la deriva - Parte 2](/blog/altscore-makers-challenge/9-nave-deriva-2) (300 points)  
   Create a phase change diagram endpoint for spaceship coolant calculations.

10. [Uncovering the Cost of Living in the Galactic Empire](/blog/altscore-makers-challenge/10-galactic-cost) (500 points)  
    A Kaggle-style data science challenge (not completed).
